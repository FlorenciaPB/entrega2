
📌 Descripción del Proyecto

Este proyecto consiste en el desarrollo de una experiencia educativa lúdica e interactiva para la web en la que el sonido actúa como el pilar central de la interacción. A través de un juego de asociación sonoro-visual, la interfaz desafía al usuario a identificar estímulos auditivos previamente editados y optimizados.

El objetivo pedagógico es ejercitar la discriminación auditiva y la atención focalizada mediante mecánicas de retroalimentación en tiempo real y puntaje.

🎧 Procesamiento y Edición de Audio

El material sonoro fue grabado y procesado utilizando herramientas de edición en DAW (Digital Audio Workstation):

Limpieza y Reducción de Ruido: Eliminación de frecuencias parásitas y ruido de fondo.

Edición y Recorte: Ajuste de tiempos de inicio y fin para evitar silencios innecesarios.

Normalización y Fades: Nivelación de ganancia y aplicación de fade-in / fade-out para evitar clics o chasquidos de audio.

Exportación Web: Optimización de archivos en formato libre de pérdida perceptible (MP3/OGG) en la carpeta /audios.

🕹️ Mecánica de Interacción (UI/UX)

Estímulo Sonoro: El usuario presiona el botón principal para reproducir la muestra de audio procesada.

Asociación Visual: Se presentan diferentes opciones gráficas entre las que se debe elegir la que corresponde al sonido escuchado.

Feedback Inmediato:

Acierto: Mensaje de confirmación visual y suma de puntos en el marcador.

Error: Alerta visual indicando intentar nuevamente.
